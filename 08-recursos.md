## Recursos que trajo Felipe (base de esta guia)

Listas "awesome" (colecciones curadas por la comunidad, buenisimas para
descubrir herramientas de un tema):

### Full stack (frontend + backend + DevOps)
- (*) **ManzDev/awesome-fullstack** - recursos de FullStack (Frontend,
  Backend y DevOps). En espanol, ideal para vos.
  https://github.com/ManzDev/awesome-fullstack

### PWA (Progressive Web Apps)
- **hemanth/awesome-pwa** - PWAs, herramientas, starters full-stack,
  generadores de manifest.json e iconos.
  https://github.com/hemanth/awesome-pwa

### Python (backend, scripting, automatizacion)
- (*) **vinta/awesome-python** - frameworks, librerias y software de Python,
  ademas de material de aprendizaje. Tiene secciones dedicadas a "Automation"
  y "Web Scraping". Tu referencia para todo lo Python.
  https://github.com/vinta/awesome-python

### Roadmap de aprendizaje (rutas por rol)
- (*) **kamranahmedse/developer-roadmap** - rutas visuales de aprendizaje
  segun el rol (frontend, backend, devops, etc.). Excelente para ver el
  "mapa completo" y no perderte. Complementa perfecto esta guia.
  https://github.com/kamranahmedse/developer-roadmap
  (Tambien vive como sitio web: roadmap.sh)

### Bots
- **arasu01/awesome-bot** - frameworks, librerias y plataformas para crear
  bots. https://github.com/arasu01/awesome-bot
- Para automatizacion Python general (scraping, tareas programadas, envio de
  correos), las secciones "Automation" y "Web Scraping" de **Awesome Python**
  cubren la base. Empeza ahi antes de buscar listas mas nicho.

## Para aprender los fundamentos (gratis y de calidad)

- **freeCodeCamp** (freecodecamp.org) - cursos interactivos gratis de HTML,
  CSS, JS, Python y mas. De los mejores para empezar de cero, haciendo.
- **The Odin Project** (theodinproject.com) - curriculum full stack gratis,
  orientado a proyectos. Muy recomendado.
- **MDN Web Docs** (developer.mozilla.org) - LA documentacion de referencia
  de HTML/CSS/JS. Cuando dudes como funciona algo de la web, se busca aca.
- **roadmap.sh** - las rutas de aprendizaje visuales (mismo del repo de
  arriba). Miralo para ubicarte.

## Documentacion oficial (leela, es tu mejor amiga)

Aprender a leer docs oficiales es una habilidad pro en si misma. Las que vas a
usar:
- **React**: react.dev (tiene un tutorial interactivo excelente).
- **Python**: docs.python.org + el tutorial oficial.
- **Supabase**: supabase.com/docs (con guias paso a paso).
- **Tailwind**: tailwindcss.com/docs (busca la clase que necesitas).
- **Vite**: vitejs.dev.
- **MDN** para cualquier cosa de la web.

## IA generativa (para profundizar)

- **Anthropic Docs** (docs.anthropic.com) - como usar Claude por API,
  prompting, tool use. Incluye una excelente guia de prompt engineering.
- **Prompt engineering guides** - busca "Anthropic prompt engineering" y
  "OpenAI prompting guide". Cortas y practicas.
- **Google AI Studio** (aistudio.google.com) - para experimentar con Gemini
  gratis y sacar tu API key (la que usa Kitradep).
- **Hugging Face** (huggingface.co) - la casa de los modelos abiertos. Para
  cuando quieras explorar mas alla de las APIs cerradas.
- Conceptos como RAG y agentes: busca tutoriales de **LangChain** o
  **LlamaIndex** (frameworks para armar apps con LLM), pero OJO: no los
  necesitas para empezar. Primero domina llamar a una API de LLM "a mano".

## Bases de datos y backend

- **Supabase docs** - tu punto de partida (BaaS).
- **FastAPI docs** (fastapi.tiangolo.com) - tutorial excelente para backend
  en Python. De los mejores docs que existen.
- **PostgreSQL Tutorial** (postgresqltutorial.com) - para aprender SQL.
- **SQLBolt** (sqlbolt.com) - aprender SQL haciendo, interactivo y corto.

## Hosting y nube

- **Hetzner** (hetzner.com) - VPS con el mejor precio/rendimiento.
- **Cloudflare** (cloudflare.com) - Pages (hosting estatico), Workers
  (serverless), DNS, todo con plan gratis generoso.
- **AWS/Azure/GCP** - sus centros de "free tier" y "getting started". OJO con
  las alertas de presupuesto (cap 06). No empieces aca; volve cuando escales.
- **Railway / Render** (railway.app / render.com) - PaaS faciles para lanzar
  backends.

## Tus propios proyectos como material de estudio (subestimadisimo)

No hay mejor referencia que codigo real que ya conoces:

- **Kitradep** (github.com/FFierroN/Kitradep) - arquitectura de bot hibrido,
  guardrails, backend intercambiable, despliegue. Lee su

- **MALP** (github.com/FFierroN/malp) - PWA full stack, componentes React,
  Tailwind con tokens, GitHub Pages. Su `GUIA_PARA_RETOMAR.md` es tu manual

- **Tu PWA del Mundial** (MIPROYECTO) - lo mas avanzado que hiciste: React +
  Supabase + Cloudflare Workers + un robot Python + muchisimo SQL. Cuando
  entiendas los capitulos, volve a leer ESE codigo: vas a entender cosas que
  antes eran magia. Es tu mejor termometro de progreso.

---

## Como no ahogarte en recursos

Regla: **1 recurso principal a la vez.** Elegí uno (ej. freeCodeCamp para JS)
y terminalo antes de saltar a otro. Saltar de recurso en recurso es otra forma
de "tutorial hell". La guia que estas leyendo + tus proyectos + la IA como
tutor alcanzan para llegar lejos.
